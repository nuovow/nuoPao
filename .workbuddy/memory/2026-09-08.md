# 2026-09-08

## 根据 init.sql 生成实体类
- 在 `com.nuo.nuopaoserver.entity` 下新建 5 个实体：User、Tag、UserTag、Team、UserTeam（对应 init.sql 的 user / tag / user_tag / team / user_team）。
- 技术栈：Spring Boot 4.1.1 + MyBatis-Plus 3.5.17 + Lombok，JDK 21。
- 关键约定：数据库字段是**驼峰命名**（如 userAccount、createTime），MyBatis-Plus 默认会把驼峰属性转成下划线列名导致 SQL 报错，因此每个驼峰字段都显式加了 `@TableField("xxx")`；`user` 表名用 `@TableName("`user`")` 加反引号避免关键字冲突。
- `isDelete` 统一加 `@TableLogic`；`user_tag` 是联合主键无 id，未设 @TableId，deleteById/updateById 不适用需自定义 SQL。

## 构建环境备忘
- `./mvnw` 会因无网络下载 Maven 失败；本机有 `D:\apache-maven-3.9.16`，需设置 `M2_HOME`/`MAVEN_HOME` 后调用 `mvn.cmd`（bash 直接调 `mvn` 会报 classworlds Launcher 找不到）。可离线 `-o` 编译。
